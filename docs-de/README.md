# Deutsche Dokumentation

Alle Anleitungen aus `docs/` gibt es hier auf Deutsch, mit denselben Dateinamen. Das englische Original in `docs/` ist maßgeblich: wenn sich beide widersprechen, gilt die englische Fassung (und die deutsche sollte nachgezogen werden).

- `docs-de/00-overview-and-principles.md`: Ziele, Sprachausgabe-Grundsätze, die Architektur auf einer Seite, Dos und Don'ts.
- `docs-de/01-setup-and-tooling.md`: Setup-Interview, Werkzeuge, Dekompilierung pro Spielversion, Build-Workflow, Hilfsskripte.
- `docs-de/02-reconnaissance.md`: Recherche: Projekt-Grundlage (Tier 1), der Slice-Ablauf G0 bis G7, Grep-Kataloge, Feature-Plan.
- `docs-de/03-architecture.md`: die Hearthstone-Access-Architektur im Detail, den Kern erstellen, Umstieg von einer alten Handler-Mod.
- `docs-de/04-building-screens.md`: eine Spiel-Oberfläche als Accessible-Klasse bauen, Checkliste pro Bildschirm.
- `docs-de/05-quality-and-updates.md`: Fehlerbehandlung, Performance, Offline-Tests, Spiel-Updates mit git diff, Screenreader-Abnahme.
- `docs-de/06-distribution.md`: Paketieren und Veröffentlichen.
- `docs-de/appendix-a-unity-loaders-harmony.md`: MelonLoader, BepInEx, Harmony, Tolk, Input System.
- `docs-de/appendix-b-unity-reflection.md`: private Felder, ReflectionHelper.
- `docs-de/appendix-c-legacy-unity.md`: Unity 5.x und älter.
- `docs-de/appendix-d-other-engines.md`: Godot, Unreal, eigene Engines.
- `docs-de/appendix-e-known-issues.md`: bekannte Kompatibilitätsprobleme.
- `docs-de/appendix-f-git-github.md`: Git und GitHub für Einsteiger.
- `CLAUDE.de.md`: die Projektregeln für Claude.

Nicht übersetzt:

- `recon/`: Recon-Werkzeuge (Englisch und Koreanisch).
- `templates/`: Code-Vorlagen.

Die frühere deutsche Lokalisierungs-Anleitung und Menü-Checkliste sind in `docs-de/03-architecture.md` (Abschnitt Lokalisierung) und `docs-de/04-building-screens.md` (Checkliste pro Bildschirm) aufgegangen.
