# Deutsche Dokumentation

Auf Deutsch gibt es:

- `docs-de/01-setup-and-tooling.md`: Setup-Interview, Werkzeuge, Dekompilierung, Build-Workflow (Kurzfassung der Phasen am Ende).
- `docs-de/appendix-a-unity-loaders-harmony.md`: MelonLoader, BepInEx, Harmony, Tolk, Input System.
- `docs/appendix-c-legacy-unity.md`: Unity 5.x und älter (liegt im englischen Ordner, ist aber auf Deutsch).
- `CLAUDE.de.md`: die Projektregeln für Claude.

Nur auf Englisch (Claude kann sie bei Bedarf zusammenfassen oder übersetzen):

- `docs/00-overview-and-principles.md`: Ziele, Sprachausgabe-Grundsätze, die Architektur auf einer Seite, Dos und Don'ts.
- `docs/02-reconnaissance.md`: Recherche: Projekt-Grundlage (Tier 1), der Slice-Ablauf G0 bis G7, Grep-Kataloge, Feature-Plan.
- `docs/03-architecture.md`: die Hearthstone-Access-Architektur im Detail, "Creating the core", Umstieg von einer alten Handler-Mod.
- `docs/04-building-screens.md`: eine Spiel-Oberfläche als Accessible-Klasse bauen, Checkliste pro Bildschirm.
- `docs/05-quality-and-updates.md`: Fehlerbehandlung, Performance, Offline-Tests, Spiel-Updates mit git diff, Screenreader-Abnahme.
- `docs/06-distribution.md`: Paketieren und Veröffentlichen.
- `docs/appendix-b-unity-reflection.md`: private Felder, ReflectionHelper.
- `docs/appendix-d-other-engines.md`: Godot, Unreal, eigene Engines.
- `docs/appendix-e-known-issues.md`: bekannte Kompatibilitätsprobleme.
- `docs/appendix-f-git-github.md`: Git und GitHub für Einsteiger.
- `recon/`: Recon-Werkzeuge (Englisch und Koreanisch).

Die frühere deutsche Lokalisierungs-Anleitung und Menü-Checkliste sind in `docs/03-architecture.md` ("Localization") und `docs/04-building-screens.md` ("Per-screen checklist") aufgegangen.
